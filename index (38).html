Changing a status. Click a status. It opens the repo on GitHub: use the gear next to About and set one topic, status-active, status-running, status-paused, status-done or status-compost. Optionally add cluster- plus a name to move a repo between clusters (e.g. cluster-anonymous-art). Archive with GitHub's own button (Settings → Archive). Reload here to see the change. Dashed statuses are first-pass suggestions until a topic replaces them.

What the activity bar measures. Public pushes from GitHub's activity feeds, last 90 days, counted in commits (one per push where GitHub doesn't give a count). Commits measure activity, not allocation: a day of thinking, making or meeting shows up blank, and a flurry of tiny commits looks busy. The grid shows the pattern; it doesn't score anyone.
